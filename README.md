# Stock Portfolio Tracker 

A simple Python-based Stock Portfolio Tracker that calculates total investment value using predefined stock prices.

## 🚀 Features

- Track multiple stocks
- Calculates total investment automatically
- Handles invalid stock names
- Prevents negative quantity input
- Saves results as:
  - `.txt` file
  - `.csv` file
- User-friendly console interaction
